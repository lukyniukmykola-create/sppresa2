# Студентський парламент ІФНТУНГ — міні-презентація

Сайт-презентація на 6 слайдів (HTML, без збірки й залежностей).

## Як опублікувати на GitHub Pages
1. Створи новий репозиторій (наприклад `sp-iftnuog-mini`) і завантаж **вміст цієї папки** в корінь (Add file → Upload files).
2. Settings → Pages → Source: `Deploy from a branch` → гілка `main`, папка `/ (root)` → Save.
3. Через 1–2 хвилини сайт буде за адресою `https://<твій-логін>.github.io/<назва-репозиторію>/`.

Хочеш у вже існуючий репозиторій? Закинь усю папку, наприклад, як `mini/` — адреса буде `.../sp-iftnuog-presentanion/mini/`.

## Структура
- `index.html` — вся презентація
- `assets/logo.png` — логотип
- `assets/img/` — фото та QR-код
- `downloads/studparlament-mini.pptx` — та сама презентація для PowerPoint
- `downloads/montserrat-fonts.zip` — шрифт Montserrat для PowerPoint (встановити перед показом)

## Як замінити фото
У `index.html` знайди блок `const PHOTOS = {` і заміни шляхи, наприклад:
`"gallery-1": "assets/img/my-photo.jpg"`. Нові фото клади в `assets/img/`.
Фото на весь слайд (`intro`) краще 1920×1080, решта — приблизно за розмірами в підказках.

## Керування
Стрілки, пробіл, клік по лівій/правій половині екрана, свайп на телефоні, `F` — повний екран.
